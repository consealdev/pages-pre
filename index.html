Highlights

Sealed on the device

Each record is encrypted with AES-256-GCM on the browser's own SubtleCrypto before it leaves. The server holds ciphertext, wrapped keys, salts and public keys, and nothing it can read.

Two factors and a recovery phrase

The account key is wrapped under a passphrase and a Secret Key kept on the device. A 24-word BIP-39 phrase, shown once, recovers it when both are lost.

Devices join by approval

A new device gets the key only when the user sees the same code on it and on a device that already holds the key, and confirms they match. The ceremony's screens come as Lit components.

Sync that merges on the client

SyncEngine moves a user's records between their devices through your backend. The server orders ciphertext, and merging runs on the client, on plaintext.

Channels between users

A channel shares one key across users. Each member holds it wrapped under their own circle key, so every device in a member's circle opens it.

A backend to match

ConsealDev.Conseal serves the sync and circle routes for ASP.NET Core. The OpenAPI spec is the contract for a backend in any other language.
