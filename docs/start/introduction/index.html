Introduction

Conseal is end-to-end encryption for web apps. Data is sealed on the user’s device before it leaves it. The server stores and orders ciphertext it can’t open. A key reaches a new device only when the user approves it on a device that already holds it, and merging runs on the client, on plaintext.

It comes in two packages:

Package For Holds
@consealdev/conseal The browser The crypto core, sync and the ceremony screens
ConsealDev.Conseal ASP.NET Core The backend for the sync and circle routes

The crypto core makes no network calls: your app owns the transport and the storage of every payload. The threat model says what Conseal covers and what it doesn’t.
